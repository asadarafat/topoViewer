# Zensical Embed Adapter

This page is a Zensical-only smoke test for the static TopoViewer adapter. It verifies that Zensical can load the shared embed assets and mount a live TopoViewer viewport from the same YAML files used by MkDocs.

```topoviewer
topology: examples/graph/basic/topology.yaml
stylesheet: examples/graph/basic/stylesheet.yaml
height: 420px
controls: true
controlsOpen: false
title: Graph basic
```
