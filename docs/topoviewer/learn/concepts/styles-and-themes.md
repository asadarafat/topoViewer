# Styles And Themes

Stylesheets keep topology facts separate from presentation. A selector chooses
objects; a style block decides how those objects render.

Use stylesheet YAML for:

- node shapes, labels, icons, badges, and status markers;
- link line width, route style, arrows, labels, and directional lanes;
- region labels, hulls, opacity, and draw order;
- runtime overlay values produced by Grafana mapper rules.
