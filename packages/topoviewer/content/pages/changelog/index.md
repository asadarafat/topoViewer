# Changelog

TopoViewer has not published a stable npm release yet. Until the first public
release, use this page as the change-policy entry point.

Release expectations:

- release notes must call out schema, style, mapper, React API, docs embed, and
  Grafana plugin changes;
- breaking changes require migration notes;
- npm publishing remains manual and gated.
