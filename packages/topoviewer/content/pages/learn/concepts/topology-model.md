# Topology Model

TopoViewer treats a diagram as data first:

- `graph` owns the topology identity and object collections.
- `layers` decide which objects are visible together.
- `nodes`, `links`, `paths`, and `regions` describe relationships.
- `labels` and `data` carry semantic facts for selectors, filters, and mapper rules.
- `stylesheet` maps those facts to presentation.

Use the [reference model](../../reference-model.md) for the deeper contract and
[object attributes](../../object-reference.md) for every field.
