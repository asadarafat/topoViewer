# Layouts

Layouts decide positions. Styles decide appearance. Keep those concerns
separate so a topology can be manually authored, generated, or auto-arranged.

Current layout paths:

- `manual` for explicit positions;
- `force` for generic graph placement;
- `clos` for inferred multi-stage CLOS fabrics.
