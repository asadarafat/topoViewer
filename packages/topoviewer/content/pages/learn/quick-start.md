# Quick Start

Render one topology before reading the full reference.

1. Start with [First topology](guides/build-your-first-topology.md).
2. Open the [browser harness](guides/browser-harness.md) when you want an authoring UI.
3. Use [Style a topology](guides/style-a-topology.md) to separate graph facts from presentation.
4. Use [Examples](../examples.md) when you want copyable YAML patterns.

## What You Need

- `topology.yaml` for graph objects and relationships.
- `stylesheet.yaml` for visual policy.
- A renderer surface: React, MkDocs, Zensical, harness, or Grafana.
