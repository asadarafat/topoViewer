# CLI And Commands

TopoViewer does not yet ship a standalone end-user CLI. The repository exposes
maintainer commands for validation, docs builds, harness preview, and release
checks.

For public users today:

- validate through the browser harness or React API;
- build docs through MkDocs/Zensical integration commands;
- export through the browser harness or runtime export APIs.
