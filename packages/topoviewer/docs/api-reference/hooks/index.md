# Hooks

TopoViewer does not yet expose a broad stable public hooks API. Prefer the
documented `TopoViewer` component and TypeScript exports until a hook is listed
as stable in the [TypeScript API](../../api-reference.md).

## Current Guidance

- Use React props and event callbacks documented in [React usage](../../learn/guides/render-in-react.md).
- Treat internal hooks as implementation details.
- Track planned API changes in the [integration roadmap](../../integration-roadmap.md).
