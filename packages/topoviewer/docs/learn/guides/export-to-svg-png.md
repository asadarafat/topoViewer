# Export To SVG Or PNG

Use exports when the topology needs to leave the interactive surface.

Current user-facing export paths:

- Browser harness: use the viewport export action for PNG review artifacts.
- React integration: use the exported runtime APIs documented in
  [React usage](render-in-react.md).
- Docs embeds: keep the live viewport as the source of truth and capture static
  images only for release or README assets.

The source of record should remain YAML.
