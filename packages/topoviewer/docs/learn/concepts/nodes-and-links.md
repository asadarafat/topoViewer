# Nodes And Links

Nodes are entities. Links are relationships. Keep operational meaning in
`labels` and `data`, then use selectors in the stylesheet and mapper.

Common patterns:

- router or service nodes connected by physical links;
- one physical link with directional telemetry using `directions`;
- service paths that traverse several nodes and links;
- regions that summarize or group related objects.
