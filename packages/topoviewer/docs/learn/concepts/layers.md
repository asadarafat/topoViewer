# Layers

Layers let one topology answer multiple questions without duplicating the graph.
A link, node, path, or region can belong to one or more layers.

Use layers for views such as:

- physical underlay;
- BGP control plane;
- service paths;
- operations or failure overlays.

Layer visibility is runtime state. The source YAML remains one topology.
